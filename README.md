# Проблема невидимых колледжей

## О проекте

Данный репозиторий содержит реализацию и материалы выпускной квалификационной работы:

> **«Проблема невидимых колледжей»**  
> Елизавета Малахова  
> СПбГУ, 2026

Проект посвящён анализу научных взаимодействий и обнаружению так называемых **невидимых колледжей** — неформальных сообществ исследователей, связанных через:

- соавторство,
- взаимное цитирование,

В работе реализован алгоритм иерархической матричной кластеризации для анализа сетей научных коммуникаций на основе данных из OpenAlex.

---

## Что такое невидимые колледжи?

Невидимые колледжи (*Invisible Colleges*) — это скрытые научные сообщества исследователей, которые активно взаимодействуют между собой через:

- совместные публикации,
- цитирование работ друг друга,
- обмен идеями,
- научное влияние.

Такие группы могут существенно влиять на развитие научных направлений, формирование исследовательской повестки и распространение знаний.
